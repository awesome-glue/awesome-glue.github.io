End-to-End Workflow

Code clean transformations with Powertools. Configure, test, and ship with the toolkit.

01

Code: Write Typed Jobs with Powertools

Eliminate boilerplate with @BatchJob. Context initialization and safe commits are handled automatically, while input parameters map to typed dataclasses or Pydantic models.

src/__main__.py Powertools for AWS Glue 
from dataclasses import dataclass
from aws_glue_powertools.jobs.spark import BatchJob, SparkJobContext

@dataclass
class JobParams:
    target_date: str
    source_bucket: str
    dry_run: bool = False

@BatchJob()
def main(args: JobParams, ctx: SparkJobContext) -> None:
    spark = ctx.glue.spark_session
    df = spark.read.parquet(f"s3://{args.source_bucket}/{args.target_date}/")
    df.write.parquet(f"{ctx.job.temp_dir}/output/")
    # Context setup and safe job.commit() handled automatically on exit

if __name__ == "__main__":
    main()
02

Setup & Ship: Configure, Test & Build with gtk

Declare dependencies in pyproject.toml. Run test suites locally inside Docker with gtk test, and generate deployment-ready wheel zips with gtk build.

pyproject.toml Job Configuration 
[project]
name = "my-glue-job"
version = "0.1.0"
dependencies = [
  "pandas>=2",
  "aws-glue-powertools"
]

[tool.aws-glue-toolkit]
glue_version = "5.1"
source = "src"
script = "__main__.py"
tests = "tests"
Terminal gtk Commands 
# Run pytest locally inside Glue Docker container
$ gtk test .

# Package deployment zips against Glue 5.1 runtime pins
$ gtk build .
# > Created my-glue-job-0.1.0.dependencies.zip
# > Created my-glue-job-0.1.0.gluewheels.zip

# Verified automatically on git commit
$ pre-commit run --all-files
