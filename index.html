Powertools for AWS Glue

Runtime Library
pip install aws-glue-powertools
Repository →

Eliminate boilerplate context management and gain typed argument validation via dataclasses or Pydantic.

etl_job/__main__.py Powertools for AWS Glue 
from dataclasses import dataclass
from datetime import date
from aws_glue_powertools.jobs.spark import BatchJob, SparkJobContext

@dataclass
class Params:
    target_date: date  # Auto-converted from CLI string

@BatchJob()
def main(args: Params, ctx: SparkJobContext) -> None:
    spark = ctx.glue.spark_session
    df = spark.read.parquet(f"s3://my-bucket/{args.target_date}/")
    df.write.parquet(f"{ctx.job.temp_dir}/output/")

if __name__ == "__main__":
    main()
02

AWS Glue Toolkit

CLI & Packaging
pip install aws-glue-toolkit
Repository →

Configure dependencies in standard pyproject.toml, run pytest inside Glue Docker containers, and generate deployment-ready wheel zips.

pyproject.toml Job Configuration 
[project]
name = "my-glue-job"
version = "0.1.0"
dependencies = [
  "aws-glue-powertools"
]

[tool.aws-glue-toolkit]
glue_version = "6.0"
source = "etl_job"
Terminal gtk Commands 
# Run pytest locally inside Glue Docker container
$ gtk test .

# Package deployment zips against Glue 6.0 runtime pins
$ gtk build .
# > Created my-glue-job-0.1.0.dependencies.zip
# > Created my-glue-job-0.1.0.gluewheels.zip

# Verified automatically on git commit
$ pre-commit run --all-files
