Powertools for AWS Glue

Implement AWS Glue best practices with automated job lifecycles, zero-boilerplate Spark sessions, and typed argument validation via dataclasses or Pydantic.

  • @BatchJob decorator with automated lifecycle and commit
  • Typed CLI parameter conversion via dataclasses or Pydantic
  • Clean Spark session setup with zero boilerplate code
etl_job/__main__.py 
from dataclasses import dataclass
from datetime import date
from aws_glue_powertools.jobs.spark import BatchJob, SparkJobContext

@dataclass
class Params:
    target_date: date  # Auto-parsed CLI string

@BatchJob()
def main(args: Params, ctx: SparkJobContext) -> None:
    spark = ctx.glue.spark_session
    df = spark.read.parquet(f"s3://bucket/{args.target_date}/")
    df.write.parquet(f"{ctx.job.temp_dir}/output/")

if __name__ == "__main__":
    main()

AWS Glue Toolkit

Configure dependencies in pyproject.toml, run pytest inside Glue Docker containers, and generate deployment wheels that resolve runtime pins automatically.

  • Standard pyproject.toml configuration and dependency management
  • gtk test for isolated local pytest execution inside Glue containers
  • gtk build packages deployment zips against runtime pins 
# Run Glue job locally inside Glue container
$ gtk run .
# > Job finished successfully in 2.31s

# Run pytest locally inside Glue Docker container
$ gtk test .
=================== 4 passed in 1.48s ===================

# Package deployment zips against Glue runtime pins
$ gtk build .
# > Created my-glue-job-0.1.0.dependencies.zip
# > Created my-glue-job-0.1.0.gluewheels.zip
